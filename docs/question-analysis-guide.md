# 真题拆解专项说明

## 功能定位

“真题拆解”是研途智伴 Agent 面向经管类考研与《数字营销》课程展示的答题训练能力。它将用户输入的论述题、简答题、案例分析题或策划题，与本地结构化题型模板匹配，输出可直接用于练习的作答框架。

## 支持题型

- 论述题：强调概念、机制、评价与启示的完整论证。
- 简答题：强调要点覆盖、层次清楚与表述准确。
- 案例分析题 / 材料分析题：强调从材料提取问题并使用理论解释。
- 策划题 / 数字营销策划题：强调目标、受众、路径、指标和风险。
- 品牌分析题与消费者行为分析题：强调品牌关系与决策机制。

## 高频场景

当前本地模板覆盖品牌社群、KOL / KOC 营销、内容种草、私域复购、AARRR 增长、直播电商、用户画像、社交媒体互动、算法推荐、数字化会员体系、品牌年轻化、口碑传播、场景营销、短视频营销、全域营销、社群共创、体验营销、数据驱动营销与 AI 生成内容等方向。

## 输出结构

真题拆解模式固定输出以下 Markdown 小标题：

1. 题目考点
2. 答题框架
3. 可用理论
4. 案例方向
5. 常见失分点
6. 示范开头
7. 建议背诵结构
8. 下一步行动

## 示例问题

- 请分析品牌社群如何影响消费者忠诚度。
- AARRR 模型如何用于数字营销增长？
- 内容种草如何影响消费者信任？
- 私域运营如何提升用户复购？
- KOL 营销如何影响消费者购买决策？
- 请拆解一道数字营销案例分析题。

## RAG 调用方式

`src/data/questionTemplates.json` 保存结构化题型模板。`retrieveKnowledge(message, "exam")` 将查询识别为 `question_analysis` 后，优先返回 `template` 片段，并将答题结构、理论、案例方向、失分点、示范开头与背诵结构传递给回答链路。

DeepSeek 服务端回答与本地 fallback 都优先读取首条匹配模板；没有精准模板时，回退到综合数字营销案例模板，仍保持同样的八段输出结构。

## 边界说明

- 模板用于答题训练和框架构建，不替代目标院校发布的专业课考试要求。
- 模板不保证与真实考试原题命中，也不代表任何院校命题范围。
- 案例方向用于组织论证，不应虚构品牌数据或未经核验的事实。
- 具体考试要求以目标院校专业课要求为准。
