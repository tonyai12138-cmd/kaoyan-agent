# 研途智伴 Agent

研途智伴 Agent 是一个面向中国考研学生的一站式智能备考服务平台，围绕择校定位、备考规划、知识库问答、真题拆解、资料核验和每日复盘提供全过程支持。

> **原创声明**：本项目为项典典老师《数字营销》课程作品项目，目前仅用于课程展示，更多详细功能亟需完善，特此以作原创声明。

## 在线体验

访问地址：[https://kaoyan-agent.vercel.app/#/](https://kaoyan-agent.vercel.app/#/)

推荐从首页开始体验完整备考流程，也可以直接进入智能问答页探索 Agent 能力。

## 项目定位

考研准备过程中，学生往往同时面临信息过载、择校焦虑、计划失控与资料真假难辨等问题。研途智伴 Agent 通过 AI Agent 与结构化知识库，将分散的信息搜索、备考规划和学习反馈整合到一个统一的网页应用中，帮助用户把模糊压力转化为可核验的选择依据和可执行的行动计划。

## 核心功能

| 功能模块 | 能力说明 |
| --- | --- |
| 考研画像诊断 | 收集背景、目标、基础与当前困扰，形成结构化备考画像。 |
| AI 择校定位报告 | 按冲刺、稳妥、保底三档给出定位方向、风险提示与核验动作。 |
| AI 备考计划生成 | 将目标拆解为今日任务、本周安排和阶段重点。 |
| 智能体问答工作台 | 支持择校咨询、计划解释、资料核验、真题拆解与情绪支持。 |
| 985 / 211 院校基础索引 | 支持院校层级、城市与类型的初步筛选。 |
| 经管类专业知识库样例 | 以可追溯状态管理重点院校专业信息样例。 |
| 真题拆解 | 面向经管类与数字营销题目输出结构化答题框架。 |
| 资料核验 | 引导用户识别信息来源，并回到官方渠道确认关键事实。 |
| 每日复盘 | 记录任务完成、困难与情绪状态，辅助调整次日节奏。 |

## 内置大模型

本项目内置 DeepSeek V4 flash 模型，用于生成智能问答、真题拆解、资料核验、计划解释和情绪支持等内容。

模型回答会结合本地知识库检索结果与系统边界规则生成，优先提供结构化、可执行的建议。模型输出不构成正式报考建议，涉及招生与考试事实的信息仍需通过官方渠道核验。

## 知识库设计

| 数据源 | 职责 |
| --- | --- |
| `src/data/universities.json` | 985 / 211 院校基础索引，提供学校层级、城市和院校类型等信息。 |
| `src/data/schools.json` | 重点院校专业知识库样例，承载专业层级字段及其来源状态。 |
| `src/data/faq.json` | 考研方法 FAQ，服务择校、计划、资料与压力管理等常见问题。 |
| `src/data/questionTemplates.json` | 经管类 / 数字营销题型模板，支持真题拆解检索。 |
| `src/data/prompts.js` | 智能体身份、模式说明、回答边界与核验提示。 |

`universities.json` 负责学校层级信息，`schools.json` 负责专业层级信息，两者通过关联字段协同检索。院校基础索引不能用于推断具体专业的考试科目、招生人数、复试线或参考书。

知识条目使用 `verified`、`partial`、`pending`、`demo` 状态标记核验程度。招生人数、复试线、参考书、考试科目等正式信息，以研招网和目标院校研究生招生官网为准。

## 技术架构

| 层次 | 技术方案 |
| --- | --- |
| 前端 | React + Vite |

## 本地运行

推荐使用 Node.js 22。

```bash
npm install
npm run dev
npm run build
```

Windows PowerShell 环境下如 `npm` 被执行策略拦截，可使用 `npm.cmd run dev`。

## 环境变量

服务端模型调用使用以下环境变量：

```dotenv
DEEPSEEK_API_KEY=your_deepseek_api_key_here
DEEPSEEK_MODEL=deepseek-v4-flash
```

- `DEEPSEEK_API_KEY` 只应配置在 Vercel 环境变量或本地 `.env.local` 中。
- 不要将真实 API Key 提交至 GitHub。
- `.env.example` 仅用于提供变量名称示例。
- 不要将 Key 写入前端代码。

## 部署说明

项目部署在 Vercel：前端由 Vite 构建，`/api/chat` 由 Vercel Serverless Function 处理模型调用。

1. 在 Vercel 中导入 GitHub 仓库。
2. Framework Preset 选择 `Vite`。
3. Build Command 设置为 `npm run build`。
4. Output Directory 设置为 `dist`。
5. 配置 `DEEPSEEK_API_KEY` 与 `DEEPSEEK_MODEL` 环境变量。
6. 部署完成后访问线上地址验证完整流程。

## 数据与使用边界

- 本系统不承诺上岸。
- 本系统不提供录取保证。
- 本系统不能替代目标院校官方招生信息。
- 院校、专业、考试科目、招生人数、复试线、参考书等信息，以研招网和目标院校研究生招生官网为准。
- 情绪陪伴仅提供学习支持和一般压力缓解建议，不替代专业心理咨询或医疗建议。
- 真题拆解仅用于答题训练和框架参考，不代表目标院校标准答案。
